# 🚀 دليل الوصول السريع للصفحات

## ✅ **كيفية تسجيل الدخول:**

### **الطريقة 1: تسجيل دخول سريع (Mock) - مُوصى بها للاختبار** ⚡

1. افتح المتصفح على: `http://localhost:3000/login`

2. اضغط على أحد الأزرار الملونة:
   - 🔴 **Admin** - للوصول لجميع الصفحات (صلاحيات كاملة)
   - 🔵 **Manager** - للوصول لصفحات المدير
   - 🟢 **Auditor** - للوصول لصفحات المدقق

3. سيتم توجيهك تلقائياً للصفحة المناسبة!

---

## 📂 **الصفحات المتاحة:**

### 🔴 **Admin (مدير النظام)**
- `/admin` - لوحة تحكم المدير
- `/ops` - بوابة العمليات (كامل الصلاحيات)
- `/dashboard` - لوحة التحكم الموحدة

### 🔵 **Manager (مدير المراجعة)**
- `/manager` - مساحة المدير
- `/manager/engagements` - المهام والتعيينات
- `/manager/findings` - نتائج المراجعة
- `/manager/reports` - التقارير
- `/ops` - مراقبة النظام (قراءة فقط)
- `/dashboard` - لوحة التحكم

### 🟢 **Auditor (المدقق)**
- `/auditor` - مساحة المدقق
- `/auditor/tasks` - المهام
- `/auditor/checklists` - قوائم التحقق
- `/auditor/archive` - الأرشيف
- `/dashboard` - لوحة التحكم

---

## 🔐 **نظام الحماية:**

### **Middleware Protection:**
- جميع الصفحات محمية تلقائياً
- `/ops` مقتصر على Admin فقط (أو Manager قراءة فقط)
- `/admin` للمسؤولين فقط
- `/manager` لـ Manager فقط
- `/auditor` لـ Auditor فقط

### **إعادة توجيه تلقائية:**
- إذا حاولت الوصول لصفحة بدون صلاحية → ستُعاد لـ `/login`
- بعد تسجيل الدخول → توجيه حسب الدور

---

## 🧪 **للاختبار:**

### **مثال 1: اختبار صلاحيات Admin**
```
1. اضغط زر Admin في صفحة login
2. ستذهب لـ /admin
3. اضغط "مدير النظام" في Header
4. ستذهب لـ /ops (صلاحيات كاملة)
```

### **مثال 2: اختبار صلاحيات Manager**
```
1. اضغط زر Manager في صفحة login
2. ستذهب لـ /manager
3. اضغط "حالة النظام" 
4. ستذهب لـ /ops (قراءة فقط + Banner أزرق)
```

### **مثال 3: اختبار صلاحيات Auditor**
```
1. اضغط زر Auditor في صفحة login
2. ستذهب لـ /auditor
3. حاول الوصول لـ /ops يدوياً
4. سيتم رفض الوصول ← العودة لـ /login
```

## 🐛 **حل المشاكل:**

### **إذا لم تظهر الصفحة:**
1. تأكد من تشغيل السيرفر: `npm run dev`
2. افتح: `http://localhost:3000/login`
3. اضغط أحد أزرار Mock Login
4. F12 → Console → تحقق من الأخطاء

### **إذا ظهرت رسالة "403 Forbidden":**
- معناها: لا صلاحية للوصول لهذه الصفحة
- الحل: ارجع لـ `/login` وسجل دخول بدور مناسب

### **إذا اختفت بيانات تسجيل الدخول:**
- الحل: سجل دخول مرة أخرى من `/login`
- أو امسح localStorage: F12 → Application → Local Storage → Clear

---

## 📝 **ملاحظات مهمة:**

⚠️ **هذا نظام Mock للاختبار فقط:**
- البيانات تُحفظ في localStorage
- لا توجد مصادقة حقيقية مع API
- عند refresh الصفحة، البيانات تبقى موجودة

✅ **للاستخدام الفعلي:**
- يجب ربط API حقيقي في `/api/auth/login`
- يجب ربط API لجلب بيانات المستخدم `/api/auth/me`
- حالياً الـ Mock يكفي للتطوير والاختبار
